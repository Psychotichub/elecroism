A Motorized Molded Case Circuit Breaker is a standard MCCB fitted with an electrical motor mechanism that allows it to be remotely switched ON/OFF and reset automatically via a control system like a BMS or PLC.

It basically converts a normal protection device into a remote-controlled circuit breaker.

1. Why motorized MCCB is used

A normal MCCB:

You must operate it manually
Cannot be controlled remotely

A motorized MCCB adds:

Remote ON command
Remote OFF (trip/reset)
Integration with BMS/SCADA
Automatic restart sequences

👉 Used in:

Hospitals
Data centers
Industrial automation
Critical loads (HVAC, pumps, gensets)
2. Main components

A motorized MCCB has:

🔹 Standard MCCB base unit
Thermal-magnetic or electronic trip unit
Short-circuit + overload protection
🔹 Motor operator unit
Small geared motor
Charges closing mechanism automatically
🔹 Closing mechanism
Spring-charged system (like ACB, but smaller scale)
🔹 Control terminals
ON coil / motor drive
OFF (shunt trip or release coil)
Feedback contacts
3. How it works (step-by-step)
🔹 A) Remote ON operation
BMS → sends ON command → Motor unit runs → Spring charges → Contacts close

Steps:

Motor rotates gear mechanism
Spring is charged
Latch releases
MCCB closes
Auxiliary contact sends “ON status”
🔹 B) Remote OFF operation
BMS → sends OFF command → Trip coil energizes → MCCB opens

Steps:

Shunt trip coil energized
Latch releases
Contacts open
Status feedback changes to OFF
🔹 C) Fault operation (automatic)
Overload → thermal trip
Short circuit → magnetic trip

👉 MCCB trips independently of motor system

🔹 D) Reset after trip

Two options:

Manual reset (local)
Motorized reset (advanced models)
4. Control wiring concept
Typical interface:
BMS DO → Motor ON command
BMS DO → Shunt Trip OFF command
BMS DI ← Status feedback (ON/OFF/TRIP)
5. Terminal functions
Terminal	Function
ON / MOTOR	Closes breaker
OFF / ST	Trips breaker
AUX NO	Closed status
AUX NC	Open status
TRIP	Fault indication
6. Difference from normal MCCB
Feature	Normal MCCB	Motorized MCCB
Remote control	❌	✅
Auto ON/OFF	❌	✅
BMS integration	❌	✅
Protection	Yes	Yes
Cost	Low	Higher
7. Important design behavior
Motor only operates mechanism, it does NOT carry load current
Protection is still handled by MCCB trip unit
Motor is energized only during switching (not continuous)
8. Safety interlocks

Motorized MCCB will NOT operate unless:

No fault condition exists
Supply control voltage is present
Mechanism is ready (spring charged state)
9. Typical use case in BMS

Example: HVAC pump control

BMS sends ON → MCCB closes → pump starts
BMS sends OFF → MCCB opens → pump stops
Fault → MCCB trips → BMS alarm
10. Engineer-level insight

Motorized MCCB is basically:

MCCB + actuator system + remote interface

It bridges:

Protection (MCCB)
Automation (BMS/PLC)
Final takeaway

A motorized Molded Case Circuit Breaker is a remote-controlled protective breaker that:

Switches loads ON/OFF via motor mechanism
Trips automatically during faults
Provides feedback to control systems
